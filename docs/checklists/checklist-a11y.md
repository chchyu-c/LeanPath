# 无障碍 Accessibility 审核清单

- [ ] 所有可交互元素有朗读标签（iOS accessibilityLabel / Android contentDescription）
- [ ] 支持系统字体放大（iOS Dynamic Type / Android sp，200% 不破版）
- [ ] 触控目标 ≥ 44pt(iOS)/48dp(Android)
- [ ] 文字与背景对比度 ≥ 4.5:1
- [ ] 不仅靠颜色传达语义（加图标/文字）
- [ ] 视频/音频提供字幕或转写
- [ ] 表单错误有文本说明，非仅红框
- [ ] 支持减少动态效果（Reduce Motion）
- [ ] 核心流程可用无障碍服务/键盘走通

> 出处：对应 references/*.md；提审前逐条核对。

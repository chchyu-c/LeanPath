# A/B 实验方案：轻计划

## 1. 假设
- 假设：改动 X 能提升指标 Y（如「新结算页」提升付费转化）。

## 2. 指标
- 主指标（北极星）：轻计划 付费转化率
- 护栏指标：崩溃率、启动耗时、卸载率

## 3. 分流
- 按 user_id 哈希分桶，保证同一用户稳定命中
- 分组：对照组 50% / 实验组 50%（或灰度 10% 起）

## 4. 样本量与周期
- 预估日活与最小可检测效应（MDE），用样本量计算器得出所需样本
- 周期建议 ≥ 1 个完整自然周，避免周末效应

## 5. 显著性
- p < 0.05 且置信区间稳定后判定；与功能开关共用分流，实验结束固化胜出版本

## 6. 风险
- 多实验并行需正交分桶，避免相互干扰
